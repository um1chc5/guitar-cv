# Fretboard Coach — docs

A browser app for learning the building blocks of electric-guitar soloing — scales, arpeggios and
box positions. You plug the guitar into an audio interface; the app shows the shape on a fretboard,
plays it for you, then listens and scores you as you play it back. No install, no account.

Live: https://um1chc5.github.io/guitar-cv/
